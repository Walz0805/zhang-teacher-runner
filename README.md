# 张老师快跑

一个模仿 2D 横版跑酷的网页版小游戏。

## 本次升级内容

- 跳跃更高、下落更快，手感更利落
- 长按加速更顺滑，速度渐进提升
- 开始界面加入标题图，整体界面更精美
- Game Over 面板加入更明显的视觉效果
- 土木学生出现概率降低，并限制为同一时间最多出现一个
- 新增随机道具：**紫色嘴唇**
- 吃到紫色嘴唇后可获得 **5 秒无敌**
- 无敌期间有发光/闪烁/粒子效果，并显示无敌倒计时
- 巧乐兹、雪碧仍然是主要障碍，刷新频率整体更平衡

## 玩法规则

- 巧乐兹：跳跃躲避
- 雪碧：下蹲躲避
- 土木学生挖掘机：跳过去；他之后会追你一小会儿，掉出屏幕后会把砖头扔到你前方，落地后形成地面障碍，需要再次跳过去
- 紫色嘴唇：拾取后进入 5 秒无敌状态
- 游戏没有终点，分数越高越好

## 操作方式

### 电脑端
- `空格 / ↑ / W`：跳跃
- `↓ / S`：下蹲
- `Shift`：加速

### 手机端
- 点击 **跳跃**：跳跃
- 长按 **下蹲**：下蹲
- 长按 **游戏画面**：加速

## 音频文件

现在只需要放这两个 MP3 文件：

- `assets/audio/1.MP3`：背景音乐，循环播放，音量较小
- `assets/audio/2.MP3`：失败后的结束语，同时也作为开始加速时的语音提示，音量较大

注意：文件名大小写要一致，建议直接命名为 `1.MP3` 和 `2.MP3`。

## 运行方式

### 方式 1：直接打开
双击 `index.html`。

### 方式 2：本地服务器（推荐）
```bash
python -m http.server 8000
```
浏览器访问：
```text
http://localhost:8000
```

## 手机端适配说明

- 电脑端保持原来的横版布局。

- 背景音乐 `1.MP4` 是循环播放的，音量已调小。
- `2.MP3` 用于失败结束语和开始加速语音，音量已调大。
